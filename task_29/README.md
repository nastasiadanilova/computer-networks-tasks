# Задание 29. Операции с IPv6-адресами

## Условие

Реализовать функции для работы с IPv6-адресами: развертывание сокращенной формы в полную, сжатие полной формы в сокращенную, проверка принадлежности адреса к подсети.
Файл: solution.py

## Функции

- `expand_ipv6(addr)` -> str - развертывает сокращенный IPv6 в полный (8 групп по 4 hex)
- `compress_ipv6(addr)` -> str - сжимает полный IPv6 в сокращенную форму (RFC 5952)
- `ipv6_in_subnet(addr, prefix)` -> bool - проверяет принадлежность адреса к подсети

## Пример вызова

```python
from solution import expand_ipv6, compress_ipv6, ipv6_in_subnet

print(expand_ipv6("2001:db8::1"))
print(expand_ipv6("::1"))
print(compress_ipv6("2001:0db8:0000:0000:0000:0000:0000:0001"))
print(compress_ipv6("0000:0000:0000:0000:0000:0000:0000:0001"))
print(ipv6_in_subnet("2001:db8::5", "2001:db8::/32"))
print(ipv6_in_subnet("2001:db9::1", "2001:db8::/32"))
```
