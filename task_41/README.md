# Задание 41. Развертывание двухсегментной сети с маршрутизацией

## Условие

Спроектировать и развернуть в Docker Compose инфраструктуру:
• Два изолированных сегмента (net_a: 10.0.1.0/24, net_b: 10.0.2.0/24)
• Контейнер-маршрутизатор с двумя интерфейсами и включенным IP forwarding
• host_a в net_a, host_b в net_b (без прямого доступа друг к другу)
• Проверка: host_a пингует host_b через маршрутизатор
Файлы: docker-compose.yml, verify.sh

## Запуск

```bash
docker compose up -d
bash verify.sh
docker compose down
```

## Критерии

- • Контейнеры запускаются без ошибок
- • host_a и host_b НЕ находятся в одной сети напрямую
- • Пинг между ними работает ТОЛЬКО через router

## Требования

- Docker Engine 24+
- Docker Compose v2
