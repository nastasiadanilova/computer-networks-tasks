# Задание 07. Многопоточный сканер портов

## Условие

Напишите функцию scan_ports(host, start, end, timeout=0.5, workers=200) -> list[dict]
Возвращает список открытых портов с дополнительной информацией (попытка получить banner).
Элемент ответа: {"port": 8080, "state": "open", "banner": "HTTP/1.0 ..."}
Banner -- первые 64 байта ответа сервера (если сервер отвечает за 1 сек), иначе "".
