# Задание 01. Перевод IP-адреса в двоичный формат

## Условие

Напишите функцию ip_to_binary(ip: str) -> str, которая принимает строку
с IPv4-адресом вида "192.168.1.1" и возвращает его двоичное представление
в формате восьми октетов, разделенных точками.

## Параметры

| | |
|---|---|
| Сигнатура | `ip_to_binary(ip: str) -> str` |
| Входные данные | строка IPv4-адреса, например "192.168.1.1" |
| Выходные данные | строка вида "11000000.10101000.00000001.00000001" |

## Пример вызова

```python
from solution import ip_to_binary
print(ip_to_binary("192.168.1.1"))
print(ip_to_binary("10.0.0.1"))
```

## Ожидаемый вывод

```
11000000.10101000.00000001.00000001
00001010.00000000.00000000.00000001
```

## Критерии приемки

- Каждый октет строго 8 бит (с ведущими нулями)
- Октеты разделены точкой
- ValueError при невалидном адресе (октет > 255 или нечисловые данные)

## Запуск

```bash
python3 solution.py
```
