# Задание 25. Симулятор протокола RIP (дистанционно-векторная маршрутизация)

## Условие

Класс RIPSimulator симулирует обмен таблицами маршрутизации по алгоритму Беллмана-Форда(основа RIP): каждый роутер рассылает свою таблицу соседям, пока таблицы не стабилизируются.
Файл: solution.py Конструктор RIPSimulator(topology: dict)topology - словарь: {"R1": {"R2": 1, "R3": 7}, ...} (ненаправленный граф)Методы
• run(max_iterations=100) -> dict - запускает симуляцию, возвращает финальные таблицы
• converged_at() -> int - номер итерации, на которой таблицы стабилизировались Структура ответа run(){  "R1": {"R1": 0, "R2": 1, "R3": 3},  "R2": {"R1": 1, "R2": 0, "R3": 2},  ...}

## Пример вызова

```python
from solution import RIPSimulator
topo = {
    "R1": {"R2": 1, "R3": 7},
    "R2": {"R1": 1, "R3": 2, "R4": 4},
    "R3": {"R1": 7, "R2": 2, "R4": 1},
    "R4": {"R2": 4, "R3": 1},
}
rip = RIPSimulator(topo)
tables = rip.run()
import pprint; pprint.pprint(tables)
print("Converged at iteration:", rip.converged_at())
```

## Ожидаемый вывод

```
{'R1': {'R1': 0, 'R2': 1, 'R3': 3, 'R4': 4},
 'R2': {'R1': 1, 'R2': 0, 'R3': 2, 'R4': 3},

 'R4': {'R1': 4, 'R2': 3, 'R3': 1, 'R4': 0}}
Converged at iteration: 3
```
